# Sources and authority

Public-source register retained from the library review dated 2026-09-20. Publication preparation does not represent a fresh verification of every external page. Recheck version-specific claims against the consuming project's actual platform.

## Package policy labels

| Label | Meaning and limit |
|---|---|
| U and U-numbered labels | Stable authoring-policy references: task and state completeness, modularity, semantic components/tokens, validation, scope and proportional verification. These are package requirements, not external research or a consuming product's approval. |
| A | Engineering requirements for canonical ownership, layering, truthful verification and workspace hygiene, as expressed in this library. |
| SC / OD | Skill packaging and official documentation workflow; the public references below provide the accessible source material. |
| PROPOSED / APPROVED AUTHORING POLICY | Authored engineering or design guidance, distinct from a project decision and from externally verified facts. |

No private project evidence, conversation attachments, personal paths or installation history is included. Historical product-specific observations are not required to use these rules and do not establish correctness in another application.
