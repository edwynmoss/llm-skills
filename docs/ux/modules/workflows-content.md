# Recurring workflows and content

Inherit RULE-BASE from [governance](../governance.md). Conditional rows require a contract when the workflow exists; they do not request new features. State ownership, uncertainty and retention are defined only in [states](states.md), validation in [validation](validation.md).

| ID | Applicability / strength | Authority/status; rationale | Expected behaviour | Exceptions / dependencies | Observable acceptance |
|---|---|---|---|---|---|
| FLOW-01 | Search/filter/sort/page; CONDITIONAL | U4E; USER REQUIREMENT; query state is not business status | Separate draft from applied query where an Apply step exists. Define query identity, ordering/tie-breaker, page reset, history URL, focus and announced results. Label partial counts; retain query after no results/error | D08; instant search need not invent Apply; query parameters must respect privacy | Slow old query cannot replace new results; Back restores matching query/results; filtering never changes persisted status |
| FLOW-02 | Selection/bulk; CONDITIONAL | U4E; USER REQUIREMENT; scope must be explicit | Model stable selected IDs or a documented all-matching query snapshot/exclusions. Label current page versus all matching. Resolve selection across filtering, pagination and permission changes; report per-item success/failure/unknown and retry only known-safe subset | D12/D05; total unavailable means no invented total | Select page, change query, remove access and run partial action: exact intended IDs processed once, results reconciled individually |
| FLOW-03 | Upload/import; CONDITIONAL | U4E + A; USER REQUIREMENT; transfer is not ingestion success | Distinguish queued/transfer/processing/validation/reconciliation/complete. Define size/type/limits from service, resumability/cancellation and source-to-canonical IDs. Define rerun, reduced input, duplicates, merge/replace/clear/conflict and partial processing | D13/D05; no fabricated processing percentage or custom uploader if suitable SDK exists | Interrupted transfer and server processing failure differ; repeat/reduced import yields intended canonical children and traceable evidence |
| FLOW-04 | Wizard/autosave/inline edit; CONDITIONAL | U4E; USER REQUIREMENT; draft is not saved truth | Define step guards, Back/Cancel, edit/cancel scope, dirty baseline, save revision, pending/failed/saved feedback and navigation restoration. Resolve autosave schedule/coalescing with canonical owner; preserve allowed draft on failure | D08/D11; no new autosave by default; concurrent edits STATE-05 | Earlier save reply cannot mark later draft saved; leave/reload and failed step recover under policy; Cancel doesn't require final validity |
| FLOW-05 | Destructive action/Undo; CONDITIONAL | U4E; USER REQUIREMENT; irreversibility must be truthful | Identify affected records/consequences and reversibility. Match confirmation to actual risk; define server-backed Undo window, eligibility and compensating side effects only if supported. Distinguish undo requested/confirmed/failed | D05; no fake local-only Undo for committed deletion; no blanket confirmation for every harmless action | Pending deletion cannot be repeated; expired/failed Undo reports actual outcome; restored consumers reflect authoritative result |
| FLOW-06 | Date/time input; CONDITIONAL | U4E + PROPOSED specificity; representation changes meaning | Choose date-only versus local civil time versus instant; name timezone and units, storage and display format. Resolve daylight-saving ambiguity/nonexistent times and rounding. Use suitable platform/library parser; localise presentation without changing canonical meaning | D14; no timezone inference from device if business owns it | Locale/date-order changes, midnight, leap day and DST boundary cases round-trip to intended value or explicit validation |
| FLOW-07 | Notifications; CONDITIONAL | U4E; USER REQUIREMENT; transient channel loses important work | Define informational/actionable/urgent purpose, placement, queue/coalescing, duration, dismissal, persistence and announcement ownership. Important failure/recovery also persists at owning scope. Avoid repeated live announcements from polling | D04/D15; product decides notification channels; no added notification service | Repeated failures remain discoverable without a toast storm; dismissing notice does not erase unresolved operation |
| FLOW-08 | Existing or explicitly requested assisted-support route; CONDITIONAL | U9; APPROVED AUTHORING POLICY informed by S6; some failures cannot be resolved by retry | Define escalation trigger, real channel/availability, permitted context transfer, user consent, draft ownership and return path. State only verified response expectations and disclose whether the original action is pending/unknown. Keep support handoff separate from task completion | D20/D07/D05; no invented team, contact channel, SLA or automatically sent message. Research need first if no support route exists | With repeated failure, user can find the actual support path; authorised context transfers without secrets or retyping avoidable data; handoff does not duplicate or falsely complete the original operation |
| CONTENT-01 | Displayed values; MUST | U4E; USER REQUIREMENT; absence is not zero | Map zero, unknown, unavailable, not applicable and unauthorised separately. Display units, precision and freshness when material. No invented production data, causes, totals or confirmations | Product vocabulary and privacy authority; unauthorised may require hiding rather than explanation | Fixture set preserves each meaning in UI and exports; unknown never participates as numeric zero |
| CONTENT-02 | Variable/localised content; MUST | U4E; USER REQUIREMENT; real content breaks ideal layout | Test long/unbroken strings, long translated labels, RTL/mixed direction, plural/zero counts, missing images, emoji/diacritics and maximum supported children. Define wrapping/truncation and accessible full-value access; maintain meaningful reading order | Use project locales and limits; stress strings clearly synthetic, not fake customer data | Primary action, identifier, error and value remain discoverable at zoom/narrow width; no identity loss through clipping |
| CONTENT-03 | Images/charts/complex media; CONDITIONAL | U4E/F; USER REQUIREMENT; information survives representation failure | Define useful alt text or decorative status, missing-image fallback and chart's textual/table equivalent including units/range/uncertainty. Resolve interaction and keyboard alternatives for chart data | No invented charts/media. Accessibility target defines applicable criteria | Image failure doesn't hide task meaning; chart's important comparisons accessible without colour or pointing |

Use scenario fixtures tied to supported bounds, not arbitrary maxima. Reachable combinations matter: no-results plus stale request, selected items plus access loss, long error plus virtual keyboard, partial import plus retry, and dirty edit plus background refresh. Select only combinations the feature can reach; justify exclusions.
